# 连续时间分窗与双层历史记忆

ExEnGraphTransformer 增加可选的 `rolling_window_size`。五个补充任务默认启用，其他配置与直接构造模型仍默认使用原全局执行路径。没有改写原始数据、变量划分、缩放或变量宏平均损失。

## 初始宽度

按“历史长度 : 窗口宽度 = 8 : 1”设置；预测段采用相同宽度，不足一窗的尾段保留。MIMIC／PhysioNet 的 24 小时历史与 24 小时预测因此共 16 窗。

| 数据集 | 原生宽度 | 模型中的归一化宽度 | 历史窗数 | 预测窗数 | 总窗数 |
| --- | --- | --- | --- | --- | --- |
| MIMIC | 3 小时 | 3 / 48 | 8 | 8 | 16 |
| PhysioNet | 3 小时 | 3 / 48 | 8 | 8 | 16 |
| Activity | 375 毫秒，即 0.375 秒 | 375 / 4000 | 8 | 3（末窗250毫秒） | 11 |
| USHCN | 3 个月 | 3 / 48 | 8 | 1（1个月） | 9 |
| DIST | 900 秒，即15分钟 | 900 / 9000 | 8 | 2 | 10 |

USHCN 的时间坐标保留记录原点，以任务起点切窗，不能根据首个观测或首个查询推断起点。数据集在样本的附加元数据列保存准确的任务起点、预测起点、终点，编码器只使用原有字段。预测起点总是切窗边界，不足一窗的区间照常保留。CPU collation 预建每窗的接收节点、合法来源前缀和分桶计划；空窗仍占据一个时间位置。

## 每窗计算

1. 用窗口起止时间查询此前有序窗口摘要，形成当前状态预期；第一窗使用可学习初态。
2. 当前节点执行时间层、组内变量层、X→Y 跨组层，默认层数仍为 4+1+3。
3. 每类注意力的 Query 加上该关系专属的窗口状态投影，保留原内容、时间、变量偏置。
4. 仅当前窗口节点更新。此前所有已知观测的最终融合表示保留在图中，可按原关系类型继续被读取；过去节点不被重写。
5. 以当前已知观测的三阶段表示、变量、角色和窗内相对时间做注意力读出。摘要加上窗口时间编码，供下一窗口的段级因果注意力使用。
6. 查询使用原预测头及 h0 残差输出；所有查询的误差统一按原训练协议计算。历史无查询窗口也参与前向和反向传播。

这同时保存具体时刻的观测信息与窗口交互模式。窗口间保留梯度，不使用 detach。没有显式滞后矩阵，也不强制段内所有注意力相等；实现并不证明模型已识别真实时变滞后或学会周期复现，需要后续实验验证。

## 信息边界

- 只有已知观测可以充当消息来源；未来 Y 值在编码前清除。
- 查询隐藏状态和预测 Y 都不进入观测记忆或窗口摘要。
- 当前窗口内仍要求来源时间不晚于接收时间，当前摘要不会反馈给本窗，因此同窗较晚 X 也不能影响较早查询。
- 预测区间只利用此前信息与按任务允许提供的 X；没有真实 Y 回填。
- 每个独立样本重置历史，不跨患者、记录、数据批次保存状态。

## 运行

沿用原入口。默认输出目录新增 `_rolling_cfg`，避免覆盖此前全局模型的结果和模型文件。

```bash
DEVICE=cuda:0 bash scripts/run_tpatch_oracle.sh activity
MODEL=exen DEVICE=cuda:0 bash scripts/run_dist.sh
```

`ROLLING_WINDOW_SIZE` 使用现有归一化时间单位；例如 Activity 0.5 秒为 `0.125`。`0` 选择原全局结构（输出目录会增加 `_rolling_0`）：

```bash
ROLLING_WINDOW_SIZE=0.125 DEVICE=cuda:0 bash scripts/run_tpatch_oracle.sh activity
ROLLING_WINDOW_SIZE=0 DEVICE=cuda:0 bash scripts/run_tpatch_oracle.sh activity
```

直接使用 `main.py --rolling-window-size ...` 时要指定独立结果目录。结果协议记录归一化宽度、原生宽度、记忆规则和完整模型参数。旧全局模型权重不能作为滚动模型完整恢复点，因为新增了窗口读出、窗口时序注意力与条件化参数。

## 实现成本

窗口按时间顺序执行；当前第一版保留全部观测表示，并对当前批次使用统一张量和接收掩码，不宣称线性复杂度或显存下降。既有分桶预算限制每次注意力块，不能限制所有窗口反向图的总显存。真实 GPU 训练的速度与峰值显存需要单独测量。

## 本轮验证（2026-11-13）

- 模型、窗口边界、分桶、原有模型和四个记录型任务：171 项相关测试通过。
- DIST 的 FullExo、HistExo、NoExo 三种一轮训练／评估导出：3 项通过。
- 前一版小窗口配置的真实 DIST 首个完整任务：19,941 节点、2,914 查询、30 个 300 秒窗口，完成 CPU 前向、反向与 Adam 参数更新；使用 hid_dim=8、1+1+1 层的小模型检查整条路径，耗时约 5.6 秒。
- 上述检查不构成预测性能改善、真实滞后恢复或周期规律学习的证据。尚未验证默认规模的完整 GPU 训练与峰值显存。
- 测试环境：`/private/tmp/rolling-graph-test-env/bin/python`。

## 默认窗口调整（2026-11-14）

默认宽度统一改为历史区间长度的八分之一；预测区间继续按同宽度切分并保留末尾短窗，不把“8:1”解释为历史窗数与预测窗数之比。五个数据集的窗口宽度、历史8窗、预测起点及总窗数均由配置测试检查。

调整后，171项模型／数据／入口回归测试与3项DIST三模式训练导出检查通过。此前300秒宽度的真实DIST检查保留在上方作为历史验证记录，不代表已对当前默认规模完成GPU训练。
